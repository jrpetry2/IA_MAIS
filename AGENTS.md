# Orientação para agentes (SaphMovel)

Este repositório define regras persistentes em [`.cursor/rules/`](.cursor/rules/). O Cursor aplica essas regras conforme o frontmatter de cada ficheiro (sempre ativo ou por padrão de ficheiros).

| Ficheiro | Quando aplica |
|----------|----------------|
| `core.mdc` | Sempre |
| `code.mdc` | Sempre (estilo de alterações) |
| `communication.mdc` | Sempre (citações, prosa) |

Para alterar o comportamento do assistente, edite ou adicione regras `.mdc` aí. Regras novas: um tema por ficheiro, texto curto e acionável.
